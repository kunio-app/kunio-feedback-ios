# Changelog

## 0.1.2

- Open status filtering through an explicit toolbar button and native selection dialog.
- Expose the active status filter to VoiceOver.
- Support clearing the filter with All statuses and dismissing the dialog with Cancel.

## 0.1.1

- Add a close button in the leading toolbar to dismiss the feedback board.
- Keep status filtering available in the trailing toolbar.
- Enlarge the empty-state suggestion button with native large control sizing and headline text.

## 0.1.0

- Native SwiftUI wishlist for iOS 17 and later.
- Anonymous feature submissions, search, status filters and voting.
- Moderation and status synchronization with Kunio.
- English and German localization, accessibility and system appearance.
- Board-scoped credentials stored in Keychain; no external dependencies.
